# 分层与重建方法

## 清单格式

`manifest.json` 至少包含 `source: {path,width,height,sha256}`、`regions: [{key,box:[x,y,w,h]}]`、`elements`、`texts` 和 `uncertainties`。元素记录 key、parentKey、role、box、zIndex、representation（native/text/vector/raster）、sourceRegion、completion（observed/inferred）、nodeId。文字记录 key、characters、box、font、fontConfidence 和 nodeId。坐标以整图为准，创建节点时减去父坐标。

## 表现选择

| 对象 | 方法 | 失败征兆 |
| --- | --- | --- |
| 平色、线性渐变、圆角卡片 | 原生形状 + 独立描边/高光/阴影 | 直接裁整张含字卡片 |
| 不规则纸张、卷轴、金属轮廓 | 原生矢量轮廓 + 独立材质层 | 粗糙矩形替代轮廓 |
| 图标、头像、绘画建筑 | 原始像素图像填充 + 精确 alpha/矢量遮罩 | 带上邻近文字或明显矩形底色 |
| 场景 | 远景、地面、建筑、前景独立素材 | 只有整张截图且 UI 烘焙在内 |
| 文案、价格、进度数字 | Figma TEXT | 原图字没去掉又叠一份字 |

## 自动补全

先判断是 UI 几何还是绘画：遮挡的圆角按钮可以由可见边缘推导完整形状；遮挡的山水建筑只能合理推断。对每个被遮挡对象保存：可见轮廓、遮挡者、缺失区域、补全依据、置信度。

用图像编辑工具生成独立透明素材或底板，目标像素和上下文紧密约束。保留原可见区域，只把缺失部分从生成图接回；无法限制修改区域时，生成图仅用作遮挡区的底层。生成结果有非预期漂移就拒收，不能将整图生成结果直接取代原图。

大型插画对象可用双遮罩保护源像素：原场景作为底层，推断图通过内缩遮罩只覆盖对象原位置，独立前景组件通过稍大的保护遮罩重新显示同坐标原图像素。默认静态画面因此仍由源像素构成，移动/隐藏对象时才露出推断区域。对象有旗杆、树枝、火花等不连通部分时使用复合子路径；每轮同时检查静态像素误差、移动后是否带走背景、隐藏后是否残留碎片。

移开测试：临时隐藏/移动组件，确认底板完整；隐藏前景建筑应看到已补全地形，而不是另一张相同建筑。卡片标题更改后原字必须消失。每种不同背景、遮挡关系至少测试一例。

## 像素与字体

先读 PNG 原尺寸。测量非透明/颜色边界与基线，别把含阴影范围当布局宽高。文字字体不可从位图唯一确定：选择候选、渲染同一短语，比较字宽、笔画、数字形态。严格区分 family 匹配、style 匹配、实际视觉匹配。

源像素要精准保留时，Figma IMAGE 裁剪变换应基于源图真实宽高计算，且保持 1:1 比例。局部素材使用独立节点，原始整图仅作为共享 imageHash，不得作为完成屏幕的未分层可见底图。
