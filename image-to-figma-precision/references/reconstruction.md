# 分层与重建方法

默认按 [acceptance.md](acceptance.md) 的约 8–9 分视觉目标，画风一致、排版准确且无溢出优先。下面的源像素保护是可选素材策略，不要求普通任务逐像素一致；严格像素检查只有明确要求时启用。排版检查见 [layout.md](layout.md)。

## 清单格式

`manifest.json` 至少包含 `source: {path,width,height,sha256}`、`regions: [{key,box:[x,y,w,h]}]`、`elements`、`texts` 和 `uncertainties`。元素记录 key、parentKey、role、box、zIndex、representation（native/text/vector/raster）、sourceRegion、completion（observed/inferred）、nodeId。文字记录 key、characters、box、font、fontConfidence 和 nodeId。坐标以整图为准，创建节点时减去父坐标。

## 表现选择

| 对象 | 方法 | 失败征兆 |
| --- | --- | --- |
| 平色、渐变、圆角卡片、按钮/标签背板 | 参考图生成无字美术资产，原生容器承载文字与布局 | 代码画形状替代美术，或把文字烘焙进底板 |
| 不规则纸张、卷轴、金属轮廓、装饰线/小菱形 | 参考图生成独立素材；技术遮罩仅用于裁剪 | 手写可见 path/SVG 或几何拼图近似造型 |
| 图标（含图标形态的道具/建筑） | 风格分析 + 逐对象文字描述 + 实际参考图，AI 独立重绘高清透明母版 | 低清截图抠图/放大、旧内区覆盖、风格漂移、缩小后不可读 |
| 头像、大型绘画建筑 | 参考图生成；用户明确指定保留时用原始资产加技术遮罩并记录例外 | 无依据扩大保留源像素的例外，带上邻近文字或背景碎片 |
| 场景 | 远景、地面、建筑、前景独立素材 | 只有整张截图且 UI 烘焙在内 |
| 文案、价格、进度数字 | Figma TEXT | 原图字没去掉又叠一份字 |

生成前按 [asset-assembly.md](asset-assembly.md) 识别重复零件、语义组和规范朝向，再读 [transparent-generation.md](transparent-generation.md)。元素另记录 assetMethod（ai-reference-redraw 或用户指定的 source-preserve）；重绘的参考、提示词、母版与目标尺寸单独保存。是否为图标由 UI 用途决定，不能把一个小建筑资源图标套入大型场景的原像素保留路线。共享 UI 背板与主体分别登记资产，不能以整体图标为最小拆解粒度。

## 自动补全

本节约束局部补全和源像素保留素材；独立重绘图标不使用“把旧可见像素接回”的策略。

先判断是 UI 几何还是绘画：遮挡的圆角按钮可由可见边缘推导完整形状，作为生图结构约束；遮挡的山水建筑只能合理推断。推导几何不授权手画可见图形。对每个被遮挡对象保存：可见轮廓、遮挡者、缺失区域、补全依据、置信度。

用图像编辑工具生成独立透明素材或底板，目标像素和上下文紧密约束。保留原可见区域，只把缺失部分从生成图接回；无法限制修改区域时，生成图仅用作遮挡区的底层。明显画风、主体或布局漂移需修复；不影响 8–9 分视觉目标的细节变化可接受。不能将整图生成结果直接取代应分层的界面。

大型插画对象可用双遮罩保护源像素：原场景作为底层，推断图通过内缩遮罩只覆盖对象原位置，独立前景组件通过稍大的保护遮罩重新显示同坐标原图像素。默认静态画面因此仍由源像素构成，移动/隐藏对象时才露出推断区域。对象有旗杆、树枝、火花等不连通部分时使用复合子路径；普通任务检查默认状态和代表性移动/隐藏状态是否有明显背景夹带或残影；严格任务再逐轮比较静态像素误差。

移开测试：临时隐藏/移动组件，确认底板完整；隐藏前景建筑应看到已补全地形，而不是另一张相同建筑。卡片标题更改后原字必须消失。每种不同背景、遮挡关系至少测试一例。

## 像素与字体

先读 PNG 原尺寸。测量非透明/颜色边界与基线，别把含阴影范围当布局宽高。文字字体不可从位图唯一确定：选择候选、渲染同一短语，比较字宽、笔画、数字形态。严格区分 family 匹配、style 匹配、实际视觉匹配。

源像素要精准保留时，Figma IMAGE 裁剪变换应基于源图真实宽高计算，且保持 1:1 比例。局部素材使用独立节点，原始整图仅作为共享 imageHash，不得作为完成屏幕的未分层可见底图。
