# 验收约定

视觉、结构和编辑性分别报告 pass/fail，全部通过才可称验收通过。只有 PNG 并不携带原设计的图层与字体，因此“完全一致”必须有实测证据，不能作为工具保证。

默认严格目标（可按用户明确标准调整，不能为通过测试临时放宽）：

- 输出宽高与原图相等；文字内容覆盖率 100%，标点/单位/大小写一致。
- 清单组件覆盖率 100%；必需文字节点全为 TEXT，opacity > 0，visible=true；无烘焙文字残留。
- 关键对象边界位置误差不超过 1 源像素；字体替代仍单独披露。
- 全图和每个关键 UI 区域 RGB MAE ≤ 3/255，超过 16/255 的像素比例 ≤ 1%；这是严格的诊断目标，并非通用感知相似度。
- 即使指标通过，也要目视复核文字/遮挡边缘及编辑性。推断区域单独报告，不计入“原始隐藏内容已还原”。
- 每个图标的独立前景导出须有真实透明区域，通过 Alpha 检查与白/黑/洋红三底色目视审核；无矩形残底、假棋盘格及杂色边缘。图集整体 Alpha 合格不能替代逐图标验收，原生遮罩也要验证导出结果。

透明素材允许轻微半透明和自然抗锯齿，例如实体 Alpha 253/255；不以“所有实体像素必须等于 255”为验收目标。结合近不透明比例、核心/高光锚点与换底视觉判断，仍拒绝明显透底、旧底色污染、假棋盘格和误删孔洞/高光。

`compare.py` 输出未经对齐的指标，禁止拿参考图对参考图的 0 误差当实际 Figma 测试。Figma 测试报告必须记录导出节点 ID、导出时间、候选图 sha256，且候选确实来自对应节点导出。

每轮至少记录：iteration、nodeId、changes、globalMetrics、regionMetrics、structureFailures、visualFailures、nextAction。全图指标改善但某关键区域恶化时，检查后回退或修复，不能只看平均数。

外部阻塞（工具权限、写入服务不可用、字体缺失且没有可接受候选）与质量失败分开。停止重复无收益尝试，保留结果并说明所需外部变化；不要宣称完成。用户要求持续迭代时，持续做有证据依据的改进，而不是无限循环同一种失败操作。
